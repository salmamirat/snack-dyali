# 🍔 Snack Dyali

Application fullstack pour gérer le menu d'un snack.

Le projet permet de gérer les plats d'un snack :
- Ajouter un plat
- Modifier un plat
- Supprimer un plat
- Afficher la liste des plats
- Gérer la disponibilité des plats


# 🛠️ Technologies utilisées

## Backend
- Node.js
- Express.js
- PostgreSQL
- Sequelize ORM
- Scalar UI (Documentation API)

## Mobile
- React Native
- Expo
- Axios
- TanStack Query
- AsyncStorage
